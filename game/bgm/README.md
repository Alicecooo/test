# BGM

三首已经挂上，都是可商用曲，不是壳之少女、恋狱或 FLOWERS 的原盘。

| 文件 | 用在 | 曲目 |
| --- | --- | --- |
| `title.mp3` | `game/config.txt` 的 `Title_bgm:title.mp3;` | HoliznaCC0《The Ocean and the Moon》，CC0 |
| `guide.mp3` | `game/scene/start.txt` 的 `bgm:guide.mp3 -volume=80 -next;` | HoliznaCC0《Moon Unit》，CC0 |
| `note.mp3` | `note-memoir.txt`、`note-shelf.txt`、`note-about.txt` 的 `bgm:note.mp3 -volume=70 -next;` | Kevin MacLeod《Night Vigil》，CC BY 4.0 |

换曲时用同名文件覆盖，或改上面那一行里的文件名。底栏「静音」会把正在播的声音关掉。出处和署名在仓库根目录 `ATTRIBUTION.md`。

笔记槽原本要挂 Back_Drop 的 Pixabay 曲《Dark Piano Ambient (Having Nothing)》。页面打不开，所以改成了《Night Vigil》。若以后拿到那首，覆盖 `note.mp3` 并改 `ATTRIBUTION.md` 里的曲名、作者和许可。不要把这些文件再上传到 Spotify 一类的流媒体。
